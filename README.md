# Repère Musculation

Programme de musculation 5 jours, saisie des séries, minuteur de repos et courbes de progression.
Application web installable sur iPhone : ouvrir le site dans Safari, puis Partager > Sur l’écran d’accueil.

Les séances sont enregistrées uniquement sur le téléphone (localStorage).

## Cap 2000

Parcours d'échecs de 400 à 2000 (ouvertures, technique, mats, finales), installable sur téléphone : `cap2000/`.
